## Workflows

Step-by-step walkthroughs of the work each role does inside Grace. Read these in order if you're learning the app end-to-end; otherwise jump to whatever you're about to do.

1. [Production setup](workflows/01-production-setup.md) — Create the org, the production, invite the team.
2. [Script → Breakdown](workflows/02-script-to-breakdown.md) — Upload a script, review the AI parse, commit the breakdown.
3. [Pre-production](workflows/03-pre-production.md) — Schedule, budget, locations, props, shot list, documents.
4. [Call sheets](workflows/04-call-sheets.md) — Build, approve, send. Daily AD cycle.
5. [Set Dashboard](workflows/05-set-dashboard.md) — Live shoot-day control. The 1st AD's home for 12 hours a day.
6. [Compliance](workflows/06-compliance.md) — Safety meetings, exhibit G, minor hours, the 8 compliance documents.
7. [Script supervisor](workflows/07-script-supervisor.md) — Continuity, takes, director picks.
8. [VFX flagging + turnover](workflows/08-vfx.md) — Flag shots, capture references, hand off to post.
9. [Editor log](workflows/09-editor-log.md) — Circled takes view, EDL / FCPXML / CSV exports for the editor.
10. [Vault](workflows/10-vault.md) — Magic-link screener delivery, daily dailies, DIT pipeline.
11. [Wrap + delivery](workflows/11-wrap.md) — Final exports, archival, what to do at wrap.

## About this guide

- **Audience**: everyone on a production — owner, AD, director, DP, sound, crew, cast.
- **Voice**: practical. Screenshots show real screens, not mockups. Steps assume you've signed in.
- **Up-to-date as of**: 2026-05. Anything in this guide reflects what's live on `app.theobeliskstudio.com`. Newer features may not be documented yet — if you see something in the app that isn't covered here, ping support and we'll get it added.

If something in the app doesn't match this guide, the app is right and this guide is stale — please open an issue against `the-obelisk-studio/grace-docs`.
